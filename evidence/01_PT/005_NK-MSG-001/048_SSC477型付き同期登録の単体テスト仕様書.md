# SSC-477 型付き同期登録の単体テスト仕様書

NK-MSG-001、WBS-G13.04／P005-02、RD MQ-003／MQ-006、UI232/233、SS311 §6.2／SS323 §3～6、SSC-477／BUG-3574／YKT-2810。対象は `LayoutHandlerRegistry` の登録と参照。入力表は確定設計SS323にある31 requestと具体的Javaデータ型の固定表。製品が参照する `LayoutRegistry`／`PayloadTypeCatalog` を試験期待値の計算に用いない。

| Test ID | 入力・操作 | 独立期待値 |
|---|---|---|
| PT-JMS-HREG001 | 固定31値のlayoutと具象request型で登録し、一つずつ照会 | 各layoutに指定した元handlerが各一つ。同型、応答・イベント登録なし |
| PT-JMS-HREG002 | 登録後に呼出元の可変listをclear。response、内部event、未知値を参照 | 確定した登録は保持。対象外の参照はすべて空 |
| PT-JMS-HREG003 | 空／1件欠けた登録、既entry重複の三条件 | 不足と重複を個別に拒否 |
| PT-JMS-HREG004 | GameList layoutにLogoutの具象型を指定 | 型不整合の固定失敗。起動済みregistryを返さない |
| PT-JMS-HREG005 | 応答、QWK、Web log、未知layoutを正契約に1件追加 | 各登録を拒否 |
| PT-JMS-HREG006 | nullのcollection／要素／layout／型／参照引数 | 各caseを構築または参照の前提で拒否 |

証拠は同sourceの選択Java25／NullAway compile、通常JUnitの6 ID、単一execの4counter、同一入力の静的3toolを照合する。登録はhandlerの業務処理を呼ばない。handlerの個別呼出、認証・Inbox、旧同期dispatcherとの配線、実JMS・DB、六製品451は依存条件として維持する。
