# BUG-030 / YKT-027 integer JDBC mapping

発見: 2026-09-08、探索`PT-SCN-20260908-explore01`。Scenario7件中3error（Game、検索条件、page）、成功には算入しない。期待値はUI234独立byte/IDで変更しない。

原因: JDBC42.7.13 `PgResultSet.getObject(int,Class)`をjavapで確認。Long分岐はSQL type BIGINT(-5)だけを許容する。Scenario共通number helperがGame.display_order(smallint)、entry.line_number(integer)にもLong.classを指定していた。整数getterと直後wasNullを使い、NULLを0へ暗黙変換しない。

横展開: `getObject(...Long.class)`の全production使用箇所をDDLと照合。AuthSessionRevocationService、LoginAttemptRepository、AuthenticationContextVerifier、LoginReplayService、LogoutReplayService、LogoutInboxServiceはいずれもapp_users.id/auth_sessions.user_id(bigint)。Scenario optional audio_file_idもaudio_files.id(bigint)。これらを不必要に変更せず、実DBの既存Auth79件と新Scenario fixtureで非回帰確認する。Scenario helperの全callerを追加query/NULL/overflow試験へ含める。

SQL/実データ/credentialは格納しない。正式run/修正commitは915/916とmanifestに追記する。
