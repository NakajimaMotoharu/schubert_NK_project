# P018-08 JaCoCo execのクラス記録境界

NK-OPS-001、WBS-P018-08.03/2、SS354のsource／byte／noMatch／不足stream。プログラムは read-only decoder。JDKのJaCoCo形式0x1007の独立構造で作る極小byte fixtureだけを用いる。当製品Coreは不変。名前とCRCは比較器の入力値としてのみ使う。

| Test ID | 手作り入力 | 期待と独立根拠 |
|---|---|---|
| PT-P01808-BIN-010 | 別のclassだけ収録 | 必須の名前が欠落、ゼロprobeに読み替えない |
| PT-P01808-BIN-011 | 同名を異なるCRCで2回収録 | その名前の同一物理を決定できないため拒否 |
| PT-P01808-BIN-012 | 同CRCの2名を収録 | 同一CRCのrecord unionを拒否 |
| PT-P01808-BIN-013 | Sessionなし、target recordは存在 | 単独原session条件を満たさない |
| PT-P01808-BIN-014 | varintで2,147,483,648を表現 | Java signed int最大値の1超過。probe配列を扱う前に拒否 |
| PT-P01808-BIN-015 | CRCの64ビットすべて1、9probe中0と8だけ1 | 16桁f、hit [0,8]、miss [1..7]。別recordは対象に加えない |
| PT-P01808-BIN-016 | 同じbyte列を可変bytearrayで渡す | read-only bytes境界違反 |
| PT-P01808-BIN-017 | 対象名に非ASCII | 明示された対象集合の契約違反 |

元PG40024の時刻9試験は保存した同readerの証拠を参照し、今回数え直さない。nativeのfresh owner、CRCの生産classとの照合、実採取、全451、formalの代替にしない。
