# API監視応答の所有解放仕様

NK-OPS-001、WBS-P018-09、RD171、UI252、SS342/351、APIMHTTP024。ApiMetricHttpHandler.handleに渡す自己所有メモリexchangeの解放を一回だけ失敗させる。候補 `9ee35bb454768ef48b4a62aca61e3a4c6ad2e1a8`。

- 正常応答後に解放失敗。HTTP値は200、固定metrics本文、Content-Type、Cache-Control、UTF-8長が元期待と一致する。解放の失敗は同じRuntimeExceptionで返り、応答・解放それぞれ一回。
- 本文書き込みと解放が同時に失敗。本文のIOExceptionを元のまま返し、解放例外を同一objectのsuppressed一件とする。ヘッダ一回、本文出力0、解放一回。借用contextは成功本文を引き続き提供する。

期待値は固定fixture、SSのメトリクス応答・所有範囲、Javaのtry-with-resourcesの例外優先規則から確定。実接続、ソケット、実HTTP、サービス起動、追加の本体変更はない。元23件の実行PG40942と当一件を合算しない。局所実行と対象クラスの同一exec測定はPG40944に保存する。
