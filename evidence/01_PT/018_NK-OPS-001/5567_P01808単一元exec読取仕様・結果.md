# P018-08の単一元exec読取

P018-08.03/2、F03/2-2、SS354、451、PT-OPS-EXEC-CRC-003、BUG-3458／YKT-2761。元の単一streamを生指標入力とする場合は `UnfilteredCodeMeasurement --strict-original-exec [--line-deficits] exec class...` を指定する。全入力を先に検査し、header一つ・順序の正しい非負時刻を持つsession一つ・execution class ID重複なしを要求する。既CRCとクラス名検査に加え、従前の独立decoder・source・owner・真正終端も正式判定で照合する。参考用の既定のオプションなしの経路は維持。

| 独立合成入力 | 元Java | 現元stream指定 | 期待の根拠 |
| --- | ---: | ---: | --- |
| 単一元＋対象のCRC一致 | 0 | 0 | 元CRCと単一session。生測定に対象行を一度出力 |
| 単一元、対象記録なし | 0 | 0 | 対象未観測は出力で false。追加引数で未到達行を出力 |
| 同IDの未到達＋到達record | 0 | 1 | 同一IDの記録を合成不能 |
| session二つ | 0 | 1 | 一つだけ |
| header追加 | 0 | 1 | 一つだけ |
| session欠落 | 0 | 1 | 元sessionを必須 |
| 負の開始時刻 | 0 | 1 | 符号付き長整数で非負 |
| 終了時刻が開始以前 | 0 | 1 | 反例4→2は不正 |

PG41084は正規2・拒否6が独立のbyte fixtureとPython判定に一致。拒否時に対象行の出力0。既定モードの六入力は元動作と一致。PG41086はHashMapをメソッド内で順に使う旧一行だけPMD生1、SpotBugs四物理の指摘・欠落・エラー各0、書式・Checkstyle 0。規則抑制0。製品PT／新しい実native／正式認定はこの群に含まれない。
