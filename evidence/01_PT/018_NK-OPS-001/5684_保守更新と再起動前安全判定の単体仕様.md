# NK-OPS-001 日次保守の更新結果と再起動前安全判定

WBS-G13.06／C02、OPS-008、UI251 §3、SS341 §4.1。対象は Batch の `MaintenanceUpdateAssessment.assess` と `SafetyChecks`。入力は固定した合成観測。終了判断を検証する。パッケージ更新・再起動の実行、実際の観測取得、公開制御と終了code30の連携、および運用記録は親仕様5677で扱う。

| Test ID | 固定した入力 | 独立期待値 |
|---|---|---|
| PT-OPS-MAINT-PREBOOT003-U01 | 更新正常、lock・package整合・filesystem・boot partition・kernel/initramfsが全て正常 | 全必要条件成立 |
| PT-OPS-MAINT-PREBOOT003-U02 | 更新警告、同じ安全確認 | 条件成立かつ更新警告を保持 |
| PT-OPS-MAINT-PREBOOT003-U03 | 各安全項目を単独で不許可とした5通り。正常更新と警告を両方適用 | 10通りとも非公開継続 |
| PT-OPS-MAINT-PREBOOT003-U04 | 更新結果欠落、更新結果未確認、または観測一式欠落 | 3通りとも非公開継続 |
| PT-OPS-MAINT-PREBOOT003-U05 | 各安全項目を単独で未確認とした5通り。更新警告 | 5通りとも非公開継続 |
| PT-OPS-MAINT-PREBOOT003-U06 | 安全項目5件全欠落 | 各観測を未確認として保持し、以前の成功にかかわらず非公開継続 |

期待値はSS341の各安全確認が必要な条件、非0でも更新警告を保持して全確認時に続行できる条件、確認不成立時に公開しない条件から固定。JDK25の合成fixtureのみ。同一候補、コマンド、終了、四coverageおよび静的解析は対応する公開manifestに記録する。
