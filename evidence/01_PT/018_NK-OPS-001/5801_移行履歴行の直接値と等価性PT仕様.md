# 移行履歴行の直接値と等価性PT仕様

| 項目 | 内容 |
|---|---|
| Program・対象 | NK-OPS-001、`SchemaHistoryAdmission.Row` の `installedRank`、`version`、`type`、`script`、`checksum`、`equals` |
| 追跡 | WBS-P019-01.02/2、WBS-G13.03（証拠参照）、UI254、SS331／343／354、PT-OPS-SCHEMA015 |
| 事前条件 | 既存PG43178の同候補二物理とJava 25。固定合成値を使用し、DB接続や移行処理を要しない。 |
| 入力と操作 | `SCHEMA` のrank 0とnullのversion/checksum、および`SQL` のrank 2、version `029`、script `V029__fixture.sql`、checksum `-2919` を構築し、各accessorを直接検証する。 |
| 独立期待値 | 発行した値との個別比較を行う。別々に構築した同値行は同じ値と判定する。rank、checksum、同一version内のscript、versionと対応scriptの変更、行種別、異なる型は区別する。等価性を製品の表示やhashから逆算しない。 |
| 観点 | 正常二種、nullable二値、同値の対称性、複数の不一致。JDBC例外、借用資源、独立した同時読取はPG43178の既存Test IDと区別し、この値試験では外部資源を使わない。 |
| 実行と証跡 | ローカルのfixture限定コンパイル後、JUnitで上記一件を選択する。対象commit、XML、終了値、依存ハッシュ、対象二物理の当実行の生coverageはPG43220の公開manifestに記録する。 |
| 判定 | この試験単独で確認できる値契約を記録し、PG43178の合格数や生coverageへ加算しない。全451、実schemaの資格、個別受入は別判定。 |
