# SSC-467 JMS受信値の通常診断の単体仕様

NK-MSG-001、MQ-001/003、UI231、SS321/351、SSC467、BUG3259/YKT2690、WBS-P005-03/P018-10.03、PT-P01810-CATALOG-019。正本mainのPR434。対象はGuardedJmsMessageの記録直後の値、明示body/metadataと通常診断。

| Test ID | 入力・独立期待値 |
| --- | --- |
| PT-JMS-DIAG-001 | 別ID・配送件数・本文長の二つの公開合成値。同じ通常診断 `GuardedJmsMessage[<redacted>]`。入力配列、返却配列の変更で元値[3,7]は変わらず、別値は空。明示accessorから元メタデータ、ID、件数を検証。値をHashSetへ入れてalias変更後も既登録を引けることを確認。 |
| PT-JMS-DIAG-002 | body欠落、metadata欠落は各NullPointerException。空bodyと欠落を区別。 |

対象の閉包はAPI値一型とJDK型だけを使うProtocol部分。JDK25.0.4/Maven3.9.12。Root NullAway、通常2件、独立XML/CRC、生四counter、公開ABIを同sourceで検証する。JmsMessageGuardTestの汎用表記の期待値だけを正本へ更新し、Artemisクライアントを含む元guard一式は現許可対象から外して未実行とする。実broker、ネットワーク、header実値を使わない。
