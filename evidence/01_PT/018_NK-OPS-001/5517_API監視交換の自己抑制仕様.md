# API監視交換の自己抑制と所有終了

NK-OPS-001／WBS-F03/2-2、P018-09、RD171、UI252、SS342／351、451、BUG-3430／YKT-2748。担当は `ApiMetricHttpHandler.handle`。借用口 `write` と公開API、HTTP値、所有する一exchangeの解放は従来の契約。候補の製品差分はこの型のみ。

APIMHTTP025のfixtureは、固定GETパスの自己所有メモリ交換、既STANDARDコンテキスト、同一のIllegalStateExceptionを投げるreadinessとclose。独立期待はJDKの自己抑制規則。IllegalArgumentExceptionを返し、そのcauseは元例外と同じ参照。元の抑制配列は空、HTTPヘッダ／本文なし、交換解放1回、借用contextが元固定本文を生成できる。旧24の正常、既例外、null、異種二重失敗と合わせ、変更後の一実行25件で確認する。

根拠は既1817、5508、固定入力とJDKの一次／二次の規則。製品コードで期待値を作らない。Java25のcompileと当classの公開ABI、JaCoCo生L/M/C/B/I、統計の同一execを記録する。実サーバ起動、TCP、VM、実DB、Root、QA056対象は含めない。実経路と全451は別。
