# SSC-461 ステップ削除サービスのJDBC例外伝播

NK-BAT-001、WBS-F02-a／P004-05／P017-07.02、RD OPS009／DAT009、UI251、SS311／332／341、BUG-3233／YKT-2680。対象は `StepCleanupService.execute/transaction` の4つの固定エラー変換前。既存のSS331の実DB単体とは別に、借用 `Connection` の純メモリportを通る局所PTを追加する。authority、期限の実値、DB/SQLの結果、実ファイルは外部へ接続しない。

| Test ID | 入力・障害注入 | 独立期待 |
| --- | --- | --- |
| STEPTX461001 | 質問の合成2chunk。継続後の空端と既存FK保留 | 2回 commit／restore、寄与1、元累積4→5、FKはdeferredで未完、同じ七bind・UTC・1000、借用close0 |
| STEPTX461002 | LOCK_BUSY、BACKUP_GATE、確定済み累計の入力差 | 固定理由かつ1rollback/restore、commitは確定済みchunkだけ、余分なSQLなし |
| STEPTX461003 | null、異種step、skip、autocommit/readOnly/isolation不一致 | 例外型と事前接続遷移0 |
| STEPTX461004 | 条件前入力にSQLExceptionまたは固定Stop、そのcause／suppressed／nextにError | 元Error参照、最初の失敗から先に進まない。通常のSQLは固定DB失敗診断 |
| STEPTX461005 | begin/rollback/restoreの既知・未知故障の組み合わせ | SS332の元Error／既知固定診断／unknown identityと固定suppressed、commit0、元借用close0 |
| STEPTX461006 | 期限0/境界/負値、割込み、commit後のclose-state変換失敗 | 期限／割込み前の開始0、確定commitをrollbackに見せず、割込み状態を試験後に所有スレッドで回収 |

期待は固定SQL位置、SS332・SS341のliteral counter、例外参照と順番を使い生産helperで算出しない。通常PTを固定sourceで実施し、独立XML・生4カウンタ、静的解析及び公開ABIを照合。生未到達、未実行の実DB全体、正式451は結果に残す。対象Core切り出しはPG38900開始記録に従う。
