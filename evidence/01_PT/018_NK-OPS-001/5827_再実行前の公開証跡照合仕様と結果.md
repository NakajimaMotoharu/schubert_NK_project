# 再実行前の公開証跡照合 仕様と結果

WBS-G08、SS354、PG44304、PG44308／PG44310。現試験ファイルと現製品クラスのSHA-256を得た段階で、両方が記録された既存公開manifestを探す。

```bash
python3 -B tools/quality/evidence_followup_index.py \
  --source <確認済みの完全GitコミットID> \
  --digest <試験ファイルのSHA-256> --digest <製品クラスのSHA-256>
```

固定したGitの追跡済み通常ファイルだけを検索する。全指定値の完全一致をそれぞれ確認したmanifestのパスを返す。作業ツリーの変更、未追跡、シンボリックリンク、private・rawの別領域は対象外。該当manifestがあっても、受入用には元の終了結果、Test ID・依存・独立oracle・CRC・除外の有無を別に照合する。候補が空の場合は各Programの元証跡索引も確認する。

既存4件と新規2件の工具単体試験が成功。現在の設定文法のfixtureとclassの組合せで先行するPG35542、PG35560、PG35563の候補を検出し、同じ組合せを持つ先行の未適用記録も区別して保持した。候補探しのための製品PTは0件。正式451の判定は未成立。
