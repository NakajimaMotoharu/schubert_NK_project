# F02 Controllerの直接ファイル生成

SS311 §5.2、SYS-005、PG-D516、WBS-F02-a（短期実行行9）、PT-F02-WEB-FILE-CTOR-001～015、BUG-3466／YKT-2768。Controllerは標準Javaの四ownerでも、ファイルを開くconstructorを使う場合は違反。既Reader・Writer・InputStream・OutputStream・AppendableやScannerの文字列内容を受けるconstructor、Controller以外の専用File adapterは本規則で許容する。

JDK25.0.4／ArchUnit1.4.2。合成bytecodeは型の初期化・ファイル操作を実行せず読み取る。独立期待は手書きの固定constructorとJDKの実シグネチャ。修正前8漏れ、修正後15/15（違反9、許可6）。既許可13 Controller sourceは現Coreで同一、対象四型名の記述0。実全JAR、当runtime、451、F02正式判定は残る。
