# NK-OPS-001 日次保守の順次停止と猶予判定

WBS-G13.06／C02、OPS-003、UI251 §3、SS341 §4.1。対象は `MaintenanceStopAssessment.hasConfirmedStops`。呼出側が同一runに属する観測を順序どおりの安定した一覧で渡す。実収集の同一性・停止手順・排他検証は親仕様5677。

| Test ID | 固定入力 | 独立期待値 |
|---|---|---|
| PT-OPS-MAINT-PREBOOT002-S01 | Caddy→Web→API→Artemis→PostgreSQL、全件確認、Web30秒とAPI60秒。Web29.999秒の対照付き | いずれも判定成立 |
| PT-OPS-MAINT-PREBOOT002-S02 | Web/API逆転、末尾欠落、重複、余剰 | 各不成立 |
| PT-OPS-MAINT-PREBOOT002-S03 | WebとAPIの上限各1ns超過、負数時間、時間未取得 | 各不成立 |
| PT-OPS-MAINT-PREBOOT002-S04 | 5段それぞれで失敗・時間切れ・不明を一つずつ注入 | 15通りとも不成立 |
| PT-OPS-MAINT-PREBOOT002-S05 | 旧run、段識別子／結果／receipt／run／一覧の欠落 | 各不成立 |

期待値はSS341 §4.1の固定順と最大待機時間、確認不成立時の更新保留から作成。終端確認フラグの由来となるCaddyの公開遮断、ArtemisのjournalとUnit result、PostgreSQLのreadinessとUnit後条件は実環境で別に照合する。単体試験は合成値を使い、停止、更新、再起動の操作を発行しない。実行source、独立照合、Tool version、四指標は対応manifestに記録する。
