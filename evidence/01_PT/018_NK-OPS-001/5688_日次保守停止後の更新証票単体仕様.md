# 日次保守で停止と更新の順序を検証する単体テスト

NK-OPS-001、OPS-003、OPS-008、UI251 §3、SS341 §4.1、BUG-3577／YKT-2812、WBS-G13.06。対象は `MaintenanceUpdateAssessment#assessAfterStops` と `UpdateReceipt`。合成の停止証票と更新証票だけを使用する。旧U01～U06の更新結果・安全項目とS01～S05の固定停止順を独立した入力で組み合わせる。

| Test ID | 入力・操作 | 独立期待値 |
|---|---|---|
| PT-OPS-MAINT-PREBOOT003-U07 | 同じ保守run、所定の停止順と猶予、停止確認後に始まる更新。警告は更新開始が停止確認の1ns後の入力を指定 | 成功は `CONDITIONS_MET`、警告は `CONDITIONS_MET_WITH_WARNING` |
| PT-OPS-MAINT-PREBOOT003-U08 | 確認済みの更新証票を固定し、停止を欠落、失敗、順序違いとする | すべて `KEEP_PRIVATE` |
| PT-OPS-MAINT-PREBOOT003-U09 | 更新証票・時刻の欠落、異runの証票、停止確認と同時刻または1ns前の開始 | すべて `KEEP_PRIVATE` |
| PT-OPS-MAINT-PREBOOT003-U10 | 停止証票が成立。同runの更新結果または安全検査が未確認 | `KEEP_PRIVATE`。後段の安全条件を維持 |

入力runと時刻は固定の合成値を使用する。実行結果と同じ製品メソッドから期待値を生成しない。判定結果は観測値の整合確認であり、実行主体や排他・実Unit・再起動を確認する証拠はC02の別条件とする。Fixtureに実コマンド、DB、JMS、native、既存保全物を使用しない。並行状態や再送を内部に持たない。再資格時は元試験と同一source/runの実行記録、coverage、静的解析、BUG/YKT、証跡SHAを結果manifestへ保存する。
