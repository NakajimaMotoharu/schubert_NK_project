# 選択した局所工程の終端証跡

| Test ID | 期待値 |
| --- | --- |
| PT-OPS-STAGES001 | 既工程名・同command・cwd・親子開始・終了・出力hash一致。許容終了0と局所PMD4を各工程へ明示 |
| PT-OPS-STAGES002 | 宣言外又は未保存の終端・不正識別子・証拠のsymlinkを拒否 |
| PT-OPS-STAGES003 | begin、process、exitの独立境界でcmd／cwd／開始の別run混入を拒否 |
| PT-OPS-STAGES004 | fail, timeout, bool型の終了値、欠落、初末時間の逆転を拒否 |
| PT-OPS-STAGES005 | stdout又はstderrの変更を拒否 |
