# SCR019 質問受付の表示単体仕様

NK-WEB-001／SCR019／QST-002／QA-048、UI224 §3、SS313／331 §9.4、WBS-F03/2-2-b。対象は QuestionAcceptedViewModel.from／getValues／getTopBar／toString。固定の仮ユーザー・技術参照・API応答値だけを使う。

| Test ID | 独立した入力 | 独立期待値 |
|---|---|---|
| PT-WEB-SCR019-VM001 | 2026-11-24 15:04:05.123456Z、参照は同じミリ秒、固定の受付ID・本文とUSER | 表示時刻 2026-11-25 00:04:05、承認された3項目、固定のブランド・ユーザー・役割、編集不可、ログ用固定文字列 |
| PT-WEB-SCR019-VM002 | ASCII 199個、200番目が補助漢字、201番目に別文字 | 199を保持。200の場合は補助漢字全体を保持し、201文字目を含めない |
| PT-WEB-SCR019-VM003 | 接続済み応答の質問ID・受付ID・受付時刻（1 msの差）・所有者を一項目ずつ変更 | 全件が固定の一致検証例外。差を発生させた項目以外は正常値 |
| PT-WEB-SCR019-VM004 | 三入力を個別にnull。本文を空にした正常構造応答 | 各nullは必須入力として拒否。空本文は固定診断で拒否 |
| PT-WEB-SCR019-VM005 | 未回答状態と回答済み日時を同時に与える | QSDRSP01の状態制約に違反し、表示用データを返さず検証例外 |

表示項目はUI224の一覧から手動固定。日付と時刻は明示的な日本時間の期待値。本文は補助文字を含む固定literalから指定する。JVM内の局所組立のみで、実HTTP、DB、JMS、生成済み業務データを使わない。表示HTMLのescape、実Web owner接続、承認済みstate全体は別試験。環境・コマンド・対象版・終了結果・coverageと各hashは実行manifestに記録する。
