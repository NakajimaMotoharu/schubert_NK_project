# DIF-007 認証画面テンプレートの静的単体テスト

PT-CHR-U02-DIF007-TPL-001。NK-WEB-001、AUT-002、UI221 §3・222 §2/4・264 DIF-007、SS313、SS355。BUG-3356／YKT-2699、WBS-P020-01.02/2。

UI221の独立した画面一覧からSCR-002〜023の22画面を個別に照合する。各テンプレートは共通headerまたはheader内の共有userActionsを一箇所参照する。UI222の共有項目として、usernameとroleのtext bindingを各一箇所、メニューlinkを一箇所、POSTのログアウトformと送信buttonを各一箇所確認する。SCR-090は認証情報がある枝だけに同じheaderを使用し、未認証枝にはログインlinkがありログアウトformを含まない。SCR-001も認証済みfragmentを使用しない。二つのpagination fragmentは画面数に含めない。

入力は実製品Coreの追跡済みテンプレートと、開始票に固定したUI/SS・Current基準tree。PythonのHTML parserでタグ、属性と親子関係を検査する。比較部品の結果や既存ログから期待値を生成しない。入力欠落・fragment重複・想定外のfragment・ログアウト方法誤りは検査失敗とする。

実行はrepo直下から `python3 -B evidence/01_PT/015_NK-WEB-001/input/4692_dif007_topbar_template_matrix.py`。対象Core、byte SHA、確認した画面、結果はPG40562のmanifestへ保存する。Main class coverage、ログ名・role実値、実HTTP・CSRF、Current／NKの同候補実DOM、補助観測schemaの承認、比較受入はこの試験の対象外。
