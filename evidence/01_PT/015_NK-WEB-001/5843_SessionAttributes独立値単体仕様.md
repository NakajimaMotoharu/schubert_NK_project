# SessionAttributes独立値単体仕様

NK-WEB-001、FUN-001/AUT-004、UI226、SS314 §7.2.1、SS331 §9.1、WBS-P015-01/2、関連F03/2-2-b。製品は `SessionAttributes` のconstructor、accessor、値比較と固定診断。既存テストのnull契約とDB試験を保全し、この限定fixtureは公開値の境界・所有・固定診断を独立に検査する。入力は合成の固定時刻・UUID・文字列・相対位置。

| Test ID | 入力・操作 | 独立の期待値 |
| --- | --- | --- |
| PT-WEB-ATTR001 | 空属性、主情報、合成GET位置、CSRF 64/128文字 | 空四属性、元主情報と固定位置、両端を保持し固定匿名診断 |
| PT-WEB-ATTR002 | 異なる10操作で構築、呼出側を逆順へ変更、返値を変更、11件で構築 | 固定10件の元順、返値変更を拒否、11件は固定件数診断 |
| PT-WEB-ATTR003 | 別目的・別時刻で同じUUID | 固定重複診断 |
| PT-WEB-ATTR004 | 63/129文字、64文字中の不正記号 | 3入力すべて固定検証診断 |
| PT-WEB-ATTR005 | 同値二集合、順序を逆にした集合 | 同値でhash一致、順序差で非等価 |

既存のF/E/S各0終端と対象・依存classを照合してJDK25の限定JUnit配置で実行する。供給値は認証用に使用しない。JaCoCo一回のexecの実測範囲を原カウンターで記録する。DB、実session・CSRF、実キー世代、正規Web包装・全製品451は範囲外。
