# SCR017 User詳細表示値の単体仕様

NK-WEB-002／FUN-009、UI225 §§5–7・UI236、SS313／314。WBS-P016-17/2。UserDetailViewModelとUserDetailResponseDataの合成値だけを用いる。

| Test ID | 入力と独立期待値 |
|---|---|
| PT-WEB-SCR017-VM001 | ADMIN閲覧・ID23・対象LOCKED、作成者と更新者を別値、全日時を別値。日またぎを含めUTCに9時間加算した固定JSTの5文字列、表示項目全15、active session数2、version 0を維持。大小文字だけが違う同一名はself。表示mapは変更不可、診断は固定。 |
| PT-WEB-SCR017-VM002 | 別名・DISABLED、active session数0。ロック理由と任意二日時は空文字、selfはfalse。 |
| PT-WEB-SCR017-VM003 | 非ADMIN、要求ID不一致、active session数3をそれぞれ拒否。actor、要求ID、dataの欠落も独立して拒否。 |

期待値はUI225・定義済みの表示契約と固定UTC時刻から作成する。固定境界2はDIF-016の承認済み上限。表示試験に実session、現アカウント、トークン、DB、HTTP、更新操作を持ち込まない。実認可と四更新操作、全451は別の終了条件を適用する。
