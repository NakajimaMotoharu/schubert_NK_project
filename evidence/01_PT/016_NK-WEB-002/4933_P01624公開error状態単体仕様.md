# P016-24 公開エラー状態一覧の単体仕様

NK-WEB-001／SCR090、WBS-P016-24、UI222、SS313 SSC047、ERROR-VALUE007。公開 `ErrorViewModel.Status.values` と `valueOf`、状態から表示HTTP値への対応。Production候補 `9ee35bb454768ef48b4a62aca61e3a4c6ad2e1a8`。

合成要求IDと空の表示snapshotを用いる。独立期待値はSS313の許容HTTP集合 `400, 401, 403, 404, 405, 409, 416, 429, 503` と、既存fixtureの固定状態名リスト。定義外状態の追加で選択集合が広がること、同じ名前のHTTP値が変わること、返却配列の変更が共有一覧へ及ぶことを検出する。定義外500相当の名前はIllegalArgumentException、nullはNullPointerException。どちらも外部処理に接続しない。状態選択はHTTP入力解析の代替試験にしない。

PG40932の固定Web成果物、現Protocol、補助依存を実行前にhash照合する。変更したTestだけをJDK25でコンパイルし、一件を独立実行。Testの書式、同一execのStatus物理のCRCと無フィルター測定を保存する。元22件は既結果を維持する。共通エラー全体の無フィルター判定では別runを合算しない。提出時は実行結果、exit、各hash、残るmapper生成命令の品質判定を明記する。
