# 通知検索formの単体テスト仕様

NK-WEB-002、SCR020、NTSREQ01、UI224 §4／UI236 §8／SS313 §5、WBS-P016-20/2。

| Test ID | 固定入力 | 独立期待値 |
| --- | --- | --- |
| PT-WEB-NFORM001 | 欠落値・空typeとACCEPTED/COMPLETED/ERROR | 空は未指定。既定page1、50件。三種類は独立の定義済みenumと一致。 |
| PT-WEB-NFORM002 | username等の未登録field、空list、type複数、未知type | owner欄を受理しない。閉じたfield errorでtyped requestを作らない。 |
| PT-WEB-NFORM003 | 999999、七桁、int overflow、先頭plus・小数・非ASCII | 六桁の境界は受理。範囲外や想定外構文はpage error。 |
| PT-WEB-NFORM004 | 閏年366日、片側、不正な逆順・範囲367日 | JST From/Toを固定UTC期待値へ変換。不正範囲はto error。 |
| PT-WEB-NFORM005 | 不存在日、不正書式、年0000、日付複数 | 入力fieldだけをエラーとして拒否。 |
| PT-WEB-NFORM006 | CR/LF/TAB/NUL、不正surrogate、未知の補助面文字 | invalid type。非列挙値からtyped requestを作らない。 |
| PT-WEB-NFORM007 | bind後に入側のlist/mapを変更、返値の更新、引数null | 元スナップショットを維持し、値を固定診断へ出さない。戻り値の更新拒否、Java非null契約で不正入力を拒否。 |

現正規Protocolのbyteを固定し、Java 25でローカルJVMの選択試験・生四指標を同一execに保存する。実通知、HTTP、JMS、DB、owner認可、実画面は別の契約として扱う。
