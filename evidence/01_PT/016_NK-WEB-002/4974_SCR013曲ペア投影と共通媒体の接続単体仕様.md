# SCR013 曲ペア投影と共通媒体の接続 単体仕様

NK-WEB-002、SCR013、RD FUN-007、UI223・235、SS313 §4・9、WBS-P016-13/2、PT-MUSIC-DOM009。

合成の格納順10・20・30を `MusicTrackViewModel.from` へ入力する。10のインストと30のメインは同じ格納キーに属し、20は同じ表示題名の単独曲。実テンプレートで2行が元順序になり、最初の行はメインとインスト、次の行は単独曲と「インストなし」になる。題名は両方「Theme」、件数は「3曲」。最初の行の再生・ダウンロード先は、メイン `voice+7` の `+` 一文字を `%2B` に変換した固定URIと、インスト `inst-7` の固定URI。表示題名の一致による誤結合、格納順の無視またはURIの二重変換を検出する。

元PT-MUSIC-DOM001～008と同じ描画helperのため同じrunで確認する。実HTTP、Browser、メディア、DB/JMS、認証サービスは使用しない。
