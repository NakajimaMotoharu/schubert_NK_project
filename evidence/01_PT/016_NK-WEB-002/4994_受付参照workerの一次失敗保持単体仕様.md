# 受付参照workerの一次失敗保持単体仕様

NK-WEB-002、SS332／354、P004-03、F03、PT-WEB-RCPTPORT012。既存001～011は以前の個別オラクルを保持する。012は自己所有のJDK ExecutorService代理に停止要求、10秒待機、false返却を独立指定し、同時に既知の別の一次AssertionErrorを投入する。停止要求と待機は一回ずつ、一次例外は同一インスタンス、終了の二次例外だけが抑制配列に一つ残ることを期待する。診断は試験の固定文言。実worker以外の副作用はない。負例代理では実スレッドも起動しない。

元の二worker競合試験は従来どおり5秒Future、10秒終了、各接続・Statement・ResultSetの別所有を確認する。実DB、HTTP、認証、公開原本、同六451は後続。結果はPG45266。
