# 質問検索formの単体テスト仕様

NK-WEB-002、SCR022、QSSREQ01、UI224 §6／UI236 §11／SS313 §5、WBS-P016-22/2。

| Test ID | 入力 | 独立期待値 |
| --- | --- | --- |
| PT-WEB-QFORM001 | USER、欠落項目と空文字 | keyword・username・状態・日付は未指定。Page=1、Page size=50。 |
| PT-WEB-QFORM002 | ADMIN、NFC前の128組のe＋結合アクセント、21漢字とASCII1文字。別名で上限超過 | 正規形のéはUTF-8で2 byte。256/64 byteは受付。2/1 byte増は該当項目エラーで要求生成を拒否。 |
| PT-WEB-QFORM003 | USERでusername、未知field、空値list・同名複数 | 閉じた項目エラー。ADMINが送信した64 byte以内の完全一致usernameは値をそのまま伝える。 |
| PT-WEB-QFORM004 | 回答状態の3字句と未知状態 | 3 enumへの対応、未知項目が検索条件に入らない。 |
| PT-WEB-QFORM005 | Pageの六桁上限、ASCII整数の構文外、七桁、int正overflow | 六桁上限で伝える。それ以外は項目エラー。 |
| PT-WEB-QFORM006 | 2024-01-01から2024-12-31、片側日付、2025-01-01まで延長、逆順 | JST端を独立UTC固定値へ換算、366日の期間内を許可。延長と逆順はtoに項目エラー。 |
| PT-WEB-QFORM007 | 存在しない暦日、不正書式、年0000、複数日付 | 対象from/toの項目エラー。 |
| PT-WEB-QFORM008 | CR/LF/TAB/NUL、unpaired surrogate、補助面の一文字 | 禁止文字と不正Unicodeで項目エラー。補助面の正規入力を保持。 |
| PT-WEB-QFORM009 | callerがmap/listを書換え。公開返値のupdate、Java非null契約 | 後から元検索条件や値が変わらない。戻りmapのupdateを拒否。Java向け引数と要素のnullは契約違反で早期拒否。固定診断は検索値を含まない。 |

Java 25の隔離作業領域で正規Protocolを使い、終了コード、実行JUnit XML、同execの未加工四指標、静的検査を保存する。HTTP、実質問照会、MQ、DB、利用者権限の実照合は対象外。
