# 質問回答明細の表示接続単体仕様

SCR023・UI224 §7・UI236・SS313。正規の画面テンプレートへ合成QuestionDetailResponseDataを製品QuestionDetailViewModelで渡す。実サービス起動を必要としない。

| Test ID | 固定入力と独立DOM期待値 |
| --- | --- |
| PT-WEB-QDETAIL-DOM001 | USER・未回答。受付ID、固定JST、質問全文、一覧hrefを表示し、所有利用者、回答、回答日時と確認UIを表示しない |
| PT-WEB-QDETAIL-DOM002 | 別ownerをADMINが閲覧。所有利用者、回答済み、空の回答という固定文言、UTC入力に9時間加えた表示。確認UIはなし |
| PT-WEB-QDETAIL-DOM003 | USER・処理エラー。エラーと質問全文を表示し、回答、回答日時と確認UIを表示しない |

既存のMapを用いたDOM試験および純粋投影試験を再演しない。実認証と削除POST、token、DB、実Browserは独立の終了条件として追跡する。
