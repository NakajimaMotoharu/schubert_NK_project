# 三つの50件一覧の上下ページ 単体仕様

NK-WEB-002、SCR015 利用者一覧、SCR020 通知一覧、SCR022 質問回答一覧、UI222 §6、SS313 §6.1。

- PT-WEB-PAGER001。121件の第2ページを表示する。表の上と下に51 - 100 / 121を表示し、前の50件・次の50件のリンクがそれぞれ同じ既存絞込み値を保持する。50行。
- PT-WEB-PAGER002。総51件。最初のページで1～50の範囲、最終ページで51～51の範囲を表示する。無い方向のリンクだけを無効にする。
- PT-WEB-PAGER003。0件で既定の空文言を表示し、リンクと範囲表示を出さない。入力不正で一覧範囲を表示しない。

合成のページ値と描画用の固定入力で現在のテンプレートを検査する。既存100件の検索とLogは共通fragmentへの影響を別に確認する。実HTTP、Browser、認証、DB、JMSを実行しない。
