# Webログ鍵単一確保と二世代分離の単体仕様

NK-MSG-002、WBS-P018-10.03、SS352、BUG-3483／YKT-2779。旧PG41348～PG41352は保全する。現仕様の構築後条件は、一個の所有配列に固定32 byteのcurrent領域と、必要なら別の固定32 byte previous領域を確保すること。借用配列のnullと幅、version、randomの固定検証がすべて成立した後に一回だけ確保する。二つの非null配列は固定幅が成立しているので、後続のcopyに二度目の鍵配列確保はない。closeは所有配列全体を消去する。

- PT-WEB-WEBLOG-OWN003。独立JCAと既固定Wireでcurrentの暗号結果、previousの旧暗号を作る。構築後に借用配列を異なる固定値で上書きしても、currentは同じ暗号結果、previousは同じ平文、close後は閉じた状態の例外。close後も借用配列の二値を維持する。
- PT-WEB-WEBLOG-OWN002-STATIC。現classの構築bytecodeで全事前検証の後に一回だけ確保し、固定32 byteのSystem.arraycopy二箇所、二度目のclone・Error捕捉なしを確認。実OOMを発生させない。旧構築の未到達handlerをcoverageへ加算しない。
