# 現移行版と旧・範囲外の区別

NK-MIG-001、SchemaHistoryAdmission.inspect、SS331 §3.3・SS343 §9.1、WBS-P019-01.02/2。Test IDはPT-OPS-SCHEMA014。V029／V030のscript名は現リポジトリの二ファイル。rank 1／2とchecksum 29／−30は固定合成値で、Flywayまたは配備済みreleaseの履歴値を表さない。JDKのConnection／PreparedStatement／ResultSet代理オブジェクトに、各列を独立に供給する。

| 入力 | 独立期待 |
| --- | --- |
| V029とV030のrank・版・名前・符号付きchecksumが全一致 | 二件とSCHEMAを元順で返す |
| V029までしかない履歴、V031へ置換した不明履歴 | 固定SQLSTATE 08001、固定診断、返却履歴なし |
| 版がV030でscript名またはchecksumだけが異なる履歴 | 同じ固定拒否。部分一致を成功にしない |
| 各経路の資源後条件 | ResultSetとStatementを各一度解放。borrowed Connectionはcloseしない |

既SCHEMA001～013と合わせて通常試験を実行し、同じ候補JAR物理と一致を測る。実DB、Flyway、切戻し、起動権限、正式451は別の受入条件。
