# 比較器とゲートの宣言名の型

NK-CHR-001、SS355 CHR-G01／G05、WBS-G04、YKT-2909、BUG-3708。対象は `ArtifactComparator` の差分定義におけるcase名とセレクター名、および共有する `GateContractValidator.strings`。

| Test ID | 入力・操作 | 独立期待値 |
|---|---|---|
| PT-CHR-DEF-018 | メモリ上の文字列二要素、Java null、JSON null、空配列、単一文字列、オブジェクト、数値またはboolean混在のJSON値を渡す。 | 正常配列は固定値 `first`／`second` を順番どおり返し、入力は不変、返却は変更不可。他の入力から名称を作らない。期待値は固定のリテラル。 |
| PT-CHR-CMP002 | 自己所有の一時領域で合成case一式を作り、既存の正常試験を実行する。 | 24caseを比較し、承認済みの16差分を認識する。 |
| PT-CHR-DEF080 | 自己所有の一時領域で、比較定義の配列が欠ける既存試験を実行する。 | 既定の `CATALOG_CASES_NOT_ARRAY` と `DIF_NOT_ARRAY` を返す。 |

JDK25、JUnit Console、既存Jackson。二つのcompare callerで同じ宣言読取を使用することをソースから照合。実CHR・全451は別の受入。
