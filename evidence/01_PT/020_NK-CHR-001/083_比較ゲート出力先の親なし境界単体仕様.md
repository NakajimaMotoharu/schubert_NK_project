# 比較ゲート出力先の親なし境界

NK-CHR-001、WBS-P020-01.03/2、SS355 比較ゲート出力／SS354 証跡。対象は `GateCli.writeJson(Path,Object,JsonOutput)`。PT-CHR-OUTPUT-ROOT-001 は現在ディレクトリから字句上のfilesystem rootを取得し、Path値としてだけ引数に使う。

期待は親ディレクトリ内の正規名を特定できない出力の拒否。独立期待値は `IllegalArgumentException`、診断 `output must name a file below a directory`、注入した四つのport呼出ゼロ。Pathの存在・権限・FileStore等は問い合わせない。常に失敗を通知する注入portを用い、既存の所有・出力順序・例外試験PG44084と分ける。実Current/NK、baseline、CLI、製品PT、全451は対象外。
