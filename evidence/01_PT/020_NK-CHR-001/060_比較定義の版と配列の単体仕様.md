# 比較定義の版と配列の単体仕様

NK-CHR-001、WBS-P020-01.02/2、RD TST-004、UI264、SS355 §5／§8／§10。対象は `ArtifactComparator.compare` と、その結果を公開する `GateCli.compareNk`。

| Test ID | 前提と操作 | 独立期待値 |
|---|---|---|
| PT-CHR-DEF077 | 自己所有の比較fixtureで、catalogの版を整数2、DIF定義の版を文字列「1」に置換する。24行と16行の内容、観測、成果物を保つ。 | FAIL。SS355の固定版と既存gate定義の版1整数から `CATALOG_VERSION` と `DIF_VERSION` の二診断を期待する。 |
| PT-CHR-DEF078 | 同じ形の別fixtureで、24行と16行を含む二つの配列を、それぞれ同順・同内容のJSON objectへ置換する。 | FAIL。正本の定義配列型から `CATALOG_CASES_NOT_ARRAY` と `DIF_NOT_ARRAY` の二診断を期待する。 |

JUnitの一時ディレクトリ内で既存fixtureの合成Current/NKを使う。既存同一比較群で正常版・正常配列、重複、欠落、観測値不正、null・入出力境界を照合する。本件に再送と並行状態は存在しない。実NK、保存Current baselineおよび稼働環境への接続は対象外。実行方法、hash、環境、終了値は対応する結果書とmanifestへ保存する。
