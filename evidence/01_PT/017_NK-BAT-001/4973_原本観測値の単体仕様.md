# Batch 原本観測値の単体仕様

Program NK-BAT-001、WBS A1-15.05 / P004-03、RD OPS-009、UI251、SS341 §3・7、SS343 §6.13・6.15、SSC-055・137。対象は `MaintenanceRunFiles.StartupOriginal` のコンストラクタ、アクセサ、値比較、診断。試験は `MaintenanceStartupOriginalValueTest`。作業前の保持全体証跡はPG44072。

| Test ID | 入力と操作 | 独立期待値 |
|---|---|---|
| PT-BAT-STARTUP-VAL-001 | 固定run・時刻・activationと空completionで生成 | 同じactivation、空completion。同じ値で再構成すると等価 |
| PT-BAT-STARTUP-VAL-002 | 全値が等しい別activation値のWARNING completionで生成 | 入力と同じcompletionを返す。pendingと区別でき、同値のhashが一致。診断は固定文字列 `StartupOriginal[identity=<redacted>]` |
| PT-BAT-STARTUP-VAL-003 | run ID、cutoff、activation IDを一項目ずつ変更した完了をそれぞれ渡す | 完了の活性識別の不一致を各々 `IllegalArgumentException` で拒否 |
| PT-BAT-STARTUP-VAL-004 | activationのnullとOptional自体のnullを別に渡す | 各構築境界で `NullPointerException`。Optional.emptyはVAL-001で対象にする |

期待値はSSのactivationとcompletionの束縛および診断の独立固定値から定義する。試験には合成値だけを用いる。実ファイル、Root、原本観測、DB・FileStore、権限や再送処理の検証は別。通常試験PG44074で正規Batch JARの対象物理を固定し、単一execの四指標・source・終了コードを対応させる。
