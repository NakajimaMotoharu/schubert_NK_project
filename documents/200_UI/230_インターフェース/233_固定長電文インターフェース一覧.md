# 固定長電文インターフェース一覧

## 1. 目的

Web/API間の全interface、layout ID、固定data長、record長、record件数、電文長上限、roleおよび仕様書を管理する。

関連RD: MQ-016～MQ-017、MQ-037～MQ-045、FUN-001～FUN-013、SCP-006。

## 2. 共通

- Headerは全layoutで256 byte。
- 表の最大長は`256 + data長 + record長 × 最大record件数`。
- 最大record件数0はrecordなし。
- Responseのpage sizeはrequestで指定するが、APIは本表の固定値以外を拒否する。
- Scenario detailだけinline上限を超える場合にlarge-result fileへ切り替える。

Web HTTP REQUESTを`app_logs`へ投影するために使用する。

## 8. Page・上限理由

- 現行検索・logは100件を維持する。最大bodyは各々約559KB、209KBで1,000,000 byte以内。
- 新規一覧は同時利用10名と画面可読性を考慮して50件。
- Scenario明細は1 record 4,800 byteのためinline 200件を上限とし、超過時はfile modeへ切り替える。
- 現行speaker 175、scenario file 262、media 20/129に将来余裕を加えた件数上限とする。
- 上限を超えた場合、暗黙に一部を欠落させず`9001`またはlarge-result modeを使用する。
