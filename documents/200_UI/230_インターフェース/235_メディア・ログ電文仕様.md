# メディア・ログ電文仕様

## 1. 目的・表記

IF-009～IF-017の要求・応答、media descriptor、一覧recordおよびLog検索項目を定める。位置は領域内の1開始相対byte位置。

関連RD: FUN-005～FUN-008、MQ-019～MQ-020、MQ-039～MQ-041、PER-004～PER-006、MON-002～MON-004。

## 2. 共通media descriptor `MEDIA1024`（1,024 byte）

AUDRSP01、VIDRSP01、MEDRSP01の固定dataに使用する。Browserへこのdescriptorを返さず、Web内部だけで使用する。

| 項目 | 開始 | 長さ | 型 | 必須 | 許容値・意味 |
|---|---:|---:|---|---|---|
| Media logical ID | 1 | 64 | X | M | 要求IDのcanonical値 |
| Relative path | 65 | 512 | X | M | Business asset root基準。絶対path禁止 |
| File name | 577 | 256 | X | M | 表示/download名 |
| File byte長 | 833 | 12 | N | M | 1以上 |
| SHA-256 | 845 | 64 | X | M | Lowercase hex |
| MIME type | 909 | 64 | X | M | 許可list内 |
| Content disposition | 973 | 1 | X | M | `I` inline、`A` attachment |
| Reserved | 974 | 51 | X | F | 全space |

Webはrelative path、size、SHA-256、MIME、dispositionを再検証し、不一致時は配信しない。配信ごとの全file SHA-256再計算は
大容量mediaの開始性能を損なうため行わず、移行manifestおよび定期integrity checkの値とmetadataを照合する。

## 3. IF-009 Audio descriptor

### 3.1 `AUDREQ01` data（16 byte）

| 項目 | 開始 | 長さ | 型 | 必須 | 許容値 |
|---|---:|---:|---|---|---|
| Audio ID | 1 | 12 | N | M | DB logical ID |
| Disposition | 13 | 1 | X | M | `I`再生/`A`download |
| Reserved | 14 | 3 | X | F | 全space |

### 3.2 `AUDRSP01` data（1,024 byte）

2章`MEDIA1024`。MIMEはinline時`audio/ogg`等の検証済み値、attachment時もfile実体に対応する値を使用する。

### 5.3 `ANLRSP01` record（928 byte、最大50件）

| 項目 | 開始 | 長さ | 型 | 必須 | 意味 |
|---|---:|---:|---|---|---|
| Video ID | 1 | 64 | X | M | Stable logical ID |
| Title | 65 | 256 | X | M | 表示title |

| Relative path | 337 | 512 | X | M | 表示用。File解決には使用しない |
| File byte長 | 849 | 12 | N | M | 1以上 |
| Parent main ID | 861 | 64 | X | C | SUBTRACK時対応main ID。他はspace |
| Display order | 925 | 4 | N | M | Category内順 |

Main画面ではParent main IDでmain/SUBTRACKを同じ行にgroup化する。
