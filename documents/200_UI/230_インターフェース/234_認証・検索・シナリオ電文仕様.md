# 認証・検索・シナリオ電文仕様

## 1. 目的・表記

IF-001～IF-008の要求・応答ごとの固定dataおよび反復record項目を定める。位置は各領域内の1開始相対byte位置。
型、必須、充填は[`232_固定長電文共通仕様.md`](232_固定長電文共通仕様.md)に従う。

関連RD: FUN-001～FUN-005、AUT-001～AUT-004、MQ-016～MQ-018、MQ-021、MQ-036～MQ-038。

## 2. 共通page応答data `PAGED48`（48 byte）

SRCRSP01および後続文書のpage一覧responseで使用する。

| 項目 | 開始 | 長さ | 型 | 必須 | 許容値・意味 |
|---|---:|---:|---|---|---|
| Effective page | 1 | 6 | N | M | 1～999999 |
| Page size | 7 | 3 | N | M | Interface固定値 |
| Total count | 10 | 9 | N | M | 0～999999999 |
| Total pages | 19 | 6 | N | M | 0件でも1 |
| First result | 25 | 9 | N | M | 0件は0 |
| Last result | 34 | 9 | N | M | 0件は0 |
| Reserved | 43 | 6 | X | F | 全space |

## 3. IF-001 Login

### 3.1 `LGNREQ01` data（384 byte）

共通headerの認証context IDは全space。

| 項目 | 開始 | 長さ | 型 | 必須 | 許容値・意味 |
|---|---:|---:|---|---|---|
| Username | 1 | 64 | X | M | NFC・trim後1～64 byte |
| Password | 65 | 256 | X | M | NFC後1～256 byte。右spaceは値の一部と区別できないため末尾space passwordは禁止 |
| Client address | 321 | 45 | X | M | IPv4/IPv6 text。Caddy検証済み |
| Reserved | 366 | 19 | X | F | 全space |

### 3.2 `LGNRSP01` data（432 byte）

| 項目 | 開始 | 長さ | 型 | 必須 | 許容値・意味 |
|---|---:|---:|---|---|---|
| Username | 1 | 64 | X | C | 成功時必須 |
| Role | 65 | 5 | X | C | `USER`/`ADMIN`、成功時必須 |
| 認証context ID | 70 | 64 | X | C | 成功時lowercase hex 64文字。header側は全space |
| 発行日時 | 134 | 17 | N | C | 成功時JST日時 |
| 期限日時 | 151 | 17 | N | C | 成功時JST日時 |
| Retry after秒 | 168 | 6 | N | M | Lock以外は0 |
| 残り試行回数 | 174 | 3 | N | M | 成功・非表示時0 |
| 利用者message | 177 | 256 | X | O | Error/lock時。成功時全space |

Result codeは成功`0000`、認証失敗`0101`、lock`0106`、一時障害`9000`。Passwordをresponseへ設定しない。

## 4. IF-002 Logout

### 4.1 `LOGREQ01` data（0 byte）

機能dataなし。共通header認証context IDが必須。

### 4.2 `LOGRSP01` data（24 byte）

| 項目 | 開始 | 長さ | 型 | 必須 | 許容値・意味 |
|---|---:|---:|---|---|---|
| Session失効日時 | 1 | 17 | N | M | JST日時 |
| Reserved | 18 | 7 | X | F | 全space |

既に失効済みの場合は`0200`で同じ失効結果を返す。

## 7. IF-005 Scenario検索

### 7.1 `SRCREQ01` data（672 byte）

| 項目 | 開始 | 長さ | 型 | 必須 | 許容値 |
|---|---:|---:|---|---|---|
| 本文keyword | 1 | 256 | X | O | 部分一致 |

### 7.2 `SRCRSP01` data（48 byte）

2章`PAGED48`。Page sizeは100。

### 7.3 `SRCRSP01` record（5,584 byte、最大100件）

| 項目 | 開始 | 長さ | 型 | 必須 | 許容値・意味 |
|---|---:|---:|---|---|---|
| Entry ID | 1 | 12 | N | M | Scenario anchor ID |
| Script file ID | 13 | 12 | N | M | 明細遷移ID |
| Game code | 25 | 12 | X | M | 定義game |
| 章title | 37 | 256 | X | O | 未設定はspace |
| Line番号 | 293 | 8 | N | M | 1以上 |
| Entry type | 301 | 10 | X | M | `dialogue`/`narration` |
| Speaker名 | 311 | 128 | X | O | Narrationはspace可 |
| 本文 | 439 | 4,096 | X | M | CR/LF/TAB/NULなし |
| Audio有無 | 4,535 | 1 | B | M | `0`/`1` |
| Audio ID | 4,536 | 12 | X | C | Audio有無1時ASCII数字、0時space |
| Script relative path | 4,548 | 512 | X | M | 表示用。File解決には使用しない |
| Audio relative path | 5,060 | 512 | X | C | Audio有無1時。表示用 |
| Reserved | 5,572 | 13 | X | F | 全space |

Record順はEntry ID昇順。本文が4,096 byteを超えるsourceは移行検証で検出し、DB投入前に変更管理する。

## 10. IF-008 Scenario明細

### 10.1 `SCNREQ01` data（12 byte）

| 項目 | 開始 | 長さ | 型 | 必須 | 意味 |
|---|---:|---:|---|---|---|
| Script file ID | 1 | 12 | N | M | 対象ID |

### 10.2 `SCNRSP01` data（1,728 byte）

| 項目 | 開始 | 長さ | 型 | 必須 | 許容値・意味 |
|---|---:|---:|---|---|---|
| Script file ID | 1 | 12 | N | M | 現在ID |
| Game code | 13 | 12 | X | M | 定義game |
| Display title | 25 | 256 | X | M | 現在title |
| Relative path | 281 | 512 | X | M | 表示用 |
| Previous file ID | 793 | 12 | X | O | ASCII数字/space |
| Previous title | 805 | 256 | X | C | Previous ID設定時 |
| Next file ID | 1,061 | 12 | X | O | ASCII数字/space |
| Next title | 1,073 | 256 | X | C | Next ID設定時 |
| Delivery mode | 1,329 | 1 | X | M | `I` inline/`F` large-result file |
| File ID | 1,330 | 36 | X | C | F時UUID |
| File relative path | 1,366 | 256 | X | C | F時transfer root基準 |
| File byte長 | 1,622 | 12 | N | M | I時0、F時実長 |
| File SHA-256 | 1,634 | 64 | X | C | F時lowercase hex |
| File record長 | 1,698 | 6 | N | M | I時0、F時`004800` |
| File record件数 | 1,704 | 9 | N | M | I時0、F時1～10000 |
| Reserved | 1,713 | 16 | X | F | 全space |

Delivery mode Iではheader record件数1～200、descriptorは未設定/0。Fではheader record件数0、descriptor必須。

### 10.3 `SCNRSP01` record（4,800 byte）

Inline bodyとlarge-result fileの両方で同じrecord layoutを使用する。

| 項目 | 開始 | 長さ | 型 | 必須 | 許容値・意味 |
|---|---:|---:|---|---|---|
| Entry ID | 1 | 12 | N | M | 同じentryの複数audio recordで同値 |
| Entry sequence | 13 | 6 | N | M | 1開始表示順 |
| Line番号 | 19 | 8 | N | M | 1以上 |
| Entry type | 27 | 10 | X | M | `dialogue`/`narration` |
| Speaker名 | 37 | 128 | X | O | Narrationはspace可 |
| 本文 | 165 | 4,096 | X | M | 同じentryでは同値 |
| Audio sequence | 4,261 | 3 | N | M | Audioなし0、あり1開始 |
| Audio ID | 4,264 | 12 | X | C | Audioあり時ASCII数字 |
| Audio relative path | 4,276 | 512 | X | C | Audioあり時、表示用 |
| Reserved | 4,788 | 13 | X | F | 全space |

Record順はEntry sequence、Audio sequence。Webは同じEntry ID/sequenceをgroup化し、本文を1回、audioを複数表示する。
