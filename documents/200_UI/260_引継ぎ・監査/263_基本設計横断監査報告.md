## 5. 横断監査で是正した事項

| ID | 事象 | 是正 |
|---|---|---|
| UI-AUD-001 | Backup失敗、個別transfer削除失敗、root異常の後続起動可否が混在 | Warning継続とroot異常停止を分離 |
| UI-AUD-002 | Artemis停止中の朝cleanupでExpiry Queue削除不能 | Artemis readiness後・API前の限定MQ保守unitへ移動 |
| UI-AUD-003 | Web/API fatal handlerにDLQ send権限なし | DLQ sendだけをapplication roleへ追加しbrowse/purge禁止 |
| UI-AUD-004 | Error responseで成功必須N/M項目を表現不能 | Result code別data/record profileとerror fillerを共通化 |
| UI-AUD-005 | Login任意日時がN型、page桁上限、0件Scenario等のIF境界不整合 | X日時、件数上限、inline 0件、状態連動Cを確定 |
| UI-AUD-006 | Web session永続化先とDB権限が未設計、context保存記述が矛盾 | 専用technical schema/role、AES-GCM、replay目的、失効再試行を設計 |
| UI-AUD-007 | Current ID再採番で検索/file順が変動 | Current順をdisplay_orderへ移行し、PK非依存化 |
| UI-AUD-008 | Storage pathとcurrent表示pathの混同 | 全media/scenario/audioでstorage/display pathを分離 |
| UI-AUD-009 | Video直リンクでtitle/category/back生成情報不足 | VIDRSP01へ固定長表示metadataを追加 |
| UI-AUD-010 | Entry/file/speaker/audioのgame一致とhas_voice/link整合が未保証 | 複合FK、link上限、has_voice導出へ変更 |
| UI-AUD-011 | TST-001/TST-004のartifact・差異管理が弱い | 264のcase設計、baseline識別、正式差異一覧、PG gateを追加 |

全事象はRD要件を変更せず基本設計内の具体化・整合是正で解決したため、QA/RDFB起票対象なしと判定した。
