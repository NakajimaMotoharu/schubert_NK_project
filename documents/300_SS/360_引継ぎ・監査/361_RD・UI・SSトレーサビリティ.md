# RD・UI・SSトレーサビリティ

## 1. 目的・判定基準

RD正本の全281要件からUI正本、SS設計、後続PG/PT/ITへのforward traceと、SS文書から上位根拠へのreverse traceを示す。
QA番号、設計判断ID、`SHA-256`表記はRD要件数に含めない。閉区間表記は実在する各IDを個別に含み、欠番を補完しない。

本書の`SS詳細化済`は設計成果物への割当完了を意味し、program実装・実機試験・移行rehearsalの完了を意味しない。
QA-041～044およびUIC-001～004はすべて承認・反映済みであり、いずれもRD変更を要しないUI内部方式の修正である。
このためRD追跡判定は変わらない。

- SS一覧: [301_詳細設計書一覧](../301_詳細設計書一覧.md)

## 13. 機械監査方法・結果

| Forward trace | 本書の閉区間を実在RD集合で展開し、RD集合との差集合を比較 | 281/281、未割当0、余分0 |
| SS decision | 各設計判断tableの`SS-D-nnn`を抽出 | SS-D-001～056、欠番0、定義重複0 |
| UI coverage | 201、211～213、221～226、231～237、241～254、261～265を§10で割当 | 未割当0 |
