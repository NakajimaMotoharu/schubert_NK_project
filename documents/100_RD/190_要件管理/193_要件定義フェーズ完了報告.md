## 4. 技術成立性の確認

2026-08-30時点の公式情報により、次を確認した。

- Ubuntu 26.04 LTS向け`openjdk-25-jdk`パッケージが提供されている。
- Spring Boot 4.1はJava 17以上26以下に対応し、Java 25を対応範囲に含む。
- Apache Artemisの現行配布版はJava 17以上を対象とし、Java 25は条件内である。
- PostgreSQL 18はサポート中で、公式方針は同majorの最新minor利用を推奨している。

参考:

- [Ubuntu 26.04 openjdk-25-jdk](https://packages.ubuntu.com/resolute/openjdk-25-jdk)
- [Spring Boot System Requirements](https://docs.spring.io/spring-boot/system-requirements.html)
- [Apache Artemis Download / Java Compatibility](https://artemis.apache.org/components/artemis/download/)
- [PostgreSQL Versioning Policy](https://www.postgresql.org/support/versioning/)
