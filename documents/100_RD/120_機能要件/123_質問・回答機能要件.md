# 質問・回答機能要件

## 1. 初期release機能

| ID | 要件 |
|---|---|
| QST-001 | Login利用者が質問要求画面から質問を入力し、送信できること。 |
| QST-002 | 質問送信後に受付IDを表示する質問受付完了画面へ遷移すること。 |
| QST-003 | 初期releaseでは外部AI serverを呼び出さず、質問保存後に空文字列の回答を作成して即時に処理済みとする。 |
| QST-004 | 空回答作成後に処理済通知を作成し、通知明細から質問と空回答を閲覧できること。 |
| QST-005 | 質問回答一覧検索画面を設け、過去の質問・回答を検索・一覧表示できること。 |
| QST-006 | 質問回答明細画面を設け、質問内容、回答内容、受付日時および回答日時を閲覧できること。 |
| QST-007 | 質問回答一覧または明細から質問・回答を削除できること。物理・論理削除と通知の扱いはQA-039で確定する。 |
| QST-008 | USER/ADMINの検索・閲覧・削除範囲はQA-040で確定する。 |

検索条件、表示項目、並び順、page size、質問最大byte数および画面layoutはUI工程で定義する。

## 2. 将来の外部AI server連携

| ID | 要件 |
|---|---|
| QST-101 | 空回答stubを外部AI server送受信adapterへ交換でき、Web画面とWeb/API間MQ interfaceへ破壊的変更を要求しないこと。 |
| QST-102 | 質問を受付順に1件ずつAI serverへ送信すること。 |
| QST-103 | AI serverから正常終了通知を受信した場合は回答を質問へ関連付け、処理済通知を作成してから次の質問へ進むこと。 |
| QST-104 | AI serverからエラー通知を受信した場合はエラー通知を作成してから次の質問へ進むこと。 |
| QST-105 | AI serverから応答がない場合は処理中のまま待機し、次の質問へ進まない。Timeout等は将来の変更管理対象とする。 |
