# スコープ定義

## 1. 今回対象

| ID | 要件 |
|---|---|
| SCP-001 | 現行のログイン、メニュー、シナリオ検索・閲覧、音声、アニメ、音楽および必要な運用機能をNKへ移行する。 |
| SCP-002 | Java 25、Spring系アプリ基盤、PostgreSQL、Apache ActiveMQ Artemisおよび起動・監視基盤を新規構築する。 |
| SCP-003 | 現行マスタからNK用DBおよびファイル配置を再構築する。 |
| SCP-004 | 現行互換性を検証する自動試験を整備する。 |
| SCP-005 | プログラム、設定雛形、構築スクリプトおよびMarkdown文書をGit管理する。 |
| SCP-006 | 質問要求・受付完了、通知情報一覧・明細、質問回答一覧検索・閲覧・削除、通知・質問・回答DB表および空回答stub処理を実装する。 |

## 2. 今回対象外

| ID | 要件 |
|---|---|
| SCP-101 | 現行のアプリログおよび監査ログは移行しない。 |
| SCP-102 | 現行Webアカウントは移行しない。 |
| SCP-103 | 現行ファイルパスの維持は要件としない。 |
| SCP-104 | 複数物理拠点または複数物理サーバによる初期HA構成は、現時点では必須としない。 |
| SCP-105 | 外部AI serverへの質問送信、外部AI serverからの結果受信、AIモデル、推論serverおよび実回答生成処理は初期releaseの対象外とする。 |

## 3. 将来拡張

| ID | 要件 |
|---|---|
| EXT-001 | 将来、初期releaseの質問・通知・回答機能へ外部AI server連携を追加できるアーキテクチャとする。 |
| EXT-002 | 初期releaseの空回答stubを外部AI server連携へ交換し、既存の質問受付画面と電文を破壊的変更せず利用できること。 |
| EXT-003 | AI質問を受付順に1件ずつ処理し、外部AI serverの正常終了通知またはエラー通知を受信後に次の要求へ進めること。 |
| EXT-004 | 外部AI serverの実回答を、初期releaseから存在する質問、回答、通知および過去検索へ関連付けられること。 |
| EXT-005 | AI実装追加時に既存の同期処理用電文へ破壊的変更を要求しない構成とする。 |

初期releaseでは質問・通知・回答の画面、DB表、MQ interfaceおよび空回答stubまで実装する。
外部AI serverとの接続、送信・受信処理および実回答生成だけを未実装とする。
